# Contributing to Librebooking-Symfony

First off, thank you for considering contributing to Librebooking-Symfony! 

## How to Contribute

### Reporting Bugs
If you find a bug, please create an issue providing as much detail as possible:
- Steps to reproduce
- Expected behavior
- Actual behavior
- Symfony/PHP version used

### Suggesting Enhancements
Enhancements can be suggested by creating an issue. Please describe the feature clearly and why it would be beneficial to the project.

### Pull Requests
1. Fork the repository
2. Create a new branch (`git checkout -b feature/amazing-feature`)
3. Make your changes
4. Ensure your code follows PSR-12 coding standards
5. Commit your changes (`git commit -m 'Add some amazing feature'`)
6. Push to the branch (`git push origin feature/amazing-feature`)
7. Open a Pull Request

## Coding Standards
This project follows the **PSR-12** coding standard. 

Thank you for contributing!
